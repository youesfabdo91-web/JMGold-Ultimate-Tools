# JMGOLD ULTIMATE TOOLS - Build Guide

## 🚀 Quick Start

### Installation
```bash
cd JMGold-Ultimate-Tools
npm install
```

### Development
```bash
npm run electron-dev
```

### Build EXE
```bash
npm run make-exe
```

Output: `dist/JMGOLD-ULTIMATE-TOOLS-v1.2-portable.exe`
